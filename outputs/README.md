# outputs/: Example Outputs

Contains example artifacts from a demo run, checked in so participants can
see expected output shape before running their own pass:

- `example_response_drafts/`, sample drafted letters, each labeled
  DRAFT, PENDING HUMAN REVIEW
- `example_review_report.csv`, sample review report: document ID,
  classification, evidence used, flag status, draft status, human-review
  status
- `example_summary.pdf`, sample "Return on Time" one-pager
