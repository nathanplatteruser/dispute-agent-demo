# Mac Setup Notes

Tested target: Apple Silicon (M1).

1. Install Python 3.10+ via Homebrew: `brew install python@3.10`
2. Install Git if not already present: `brew install git`
3. Follow `setup/install.md` from Step 2.
4. Ollama installs natively on Apple Silicon, no Rosetta needed. Confirm
   with `ollama --version` after install.
