# Data: Synthetic Only

Everything in this directory is fictional and synthetically generated.
No real consumer names, account numbers, addresses, creditor data, or
production correspondence appears anywhere in this repo.

- `sample_disputes/`, ~20 fictional dispute documents for the live demo run,
  covering debt-verification, payment/balance, liability, and fee-related
  disputes, plus a few requiring escalation rather than automated drafting.
- `mock_reference_data/`, a fictional collections agency's mock account
  history, used as the "known facts" the tool compares dispute claims
  against.

Every file in both folders is labeled as synthetic training data at the top
of the file.
