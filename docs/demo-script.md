# Demo Script: Prompt Sequence

Structured, not open-ended. Attendees follow along prompt by prompt rather
than choosing their own project.

## 1. Define the workflow

- Identify which dispute types can be screened first
- Separate automation candidates from required human-escalation cases

See `prompts/01_define-workflow.md`

## 2. Classify the incoming disputes

- Categorize each mock document
- Identify incomplete or ambiguous cases

See `prompts/02_classify-dispute.md`

## 3. Check factual accuracy

- Compare claims in each dispute against mock reference data
- Flag only factually incorrect claims for the core demo

See `prompts/03_check-factual-claims.md`

## 4. Draft a response for human review

- Produce a draft, the evidence used, and an escalation flag where applicable

See `prompts/04_draft-human-review-response.md`

## 5. Operationalize safely

- What controls, data rules, approvals, monitoring, and compliance checks
  would be needed before real deployment

See `prompts/05_operationalize-and-risk-review.md`
