# Prompt 5: Operationalize and Risk Review

Given the workflow demonstrated in Prompts 1-4, list what would need to be in
place before any version of this ran against real consumer data:

- Data controls (storage, retention, access, encryption)
- Approval workflow (who signs off, at what step, with what audit trail)
- Monitoring (accuracy drift, error rates, escalation volume)
- Compliance checks (FDCPA, Regulation F / 12 CFR Part 1006, state-specific
  rules)
- Security review (model access, data exfiltration risk, prompt injection
  from ingested dispute text)

Output: a short risk-and-controls list, explicitly framed as a starting point
for legal, compliance, and security teams, not a completed review.
